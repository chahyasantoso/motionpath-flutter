# motionpath_core

Pure Dart MotionPath v4 engine. It validates v4 projects, compiles observation graphs, interpolates authored stops, composes renderer-neutral patches, and runs headlessly without Flutter.

Start with [`docs/API.md`](../../docs/API.md) and [`docs/COMPATIBILITY.md`](../../docs/COMPATIBILITY.md). The package intentionally owns no frame source, platform API, image loader, CSS serializer, or widget layout.
